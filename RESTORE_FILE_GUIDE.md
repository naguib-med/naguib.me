# Pour restaurer le fichier dual-expertise-banner.tsx

## Option 1: Restaurer depuis Git (si le fichier était dans un commit précédent)
```bash
cd "D:\portfolio projects\naguib.me"
git checkout HEAD -- components/dual-expertise-banner.tsx
```

## Option 2: Voir l'historique et choisir une version spécifique
```bash
cd "D:\portfolio projects\naguib.me"
git log --oneline -- components/dual-expertise-banner.tsx
git checkout <commit-hash> -- components/dual-expertise-banner.tsx
```

## Option 3: Annuler toutes les modifications non commitées
```bash
cd "D:\portfolio projects\naguib.me"
git restore components/dual-expertise-banner.tsx
```

Le fichier actuel semble correct et correspond au design moderne créé précédemment.
